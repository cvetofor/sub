# AmoCRM: подключение сайта подписок

Инструкция описывает, как подключить сайт подписок к AmoCRM так, чтобы новая
заявка создавала сделку автоматически, а первая оплата переводила её на
выбранный этап. Токен — это секретный ключ доступа: его нельзя отправлять в
чат, сохранять в Git или прикладывать к задаче.

## Что будет происходить после включения

1. Посетитель оформляет подписку на сайте.
2. Сайт создаёт в AmoCRM одну сделку с контактом, суммой, данными доставки и
   примечанием.
3. В примечании есть отдельная защищённая ссылка «только просмотр» на карточку
   заявки. Вход на сайт по ней не нужен, но изменить ничего нельзя.
4. После первой успешной оплаты сайт меняет сумму сделки, переводит её на
   выбранный этап и добавляет примечание об оплате.

## Что нужно до настройки

- Права администратора в нужном аккаунте AmoCRM.
- Решение, какая воронка будет принимать подписки, на каком этапе они будут
  сразу после оформления и на каком — после оплаты.
- Доступ к GitHub-репозиторию `cvetofor/sub` для добавления защищённого секрета.

## Создать частную интеграцию в AmoCRM

1. В AmoCRM откройте **Настройки** → **Интеграции**.
2. Нажмите **Создать интеграцию** и выберите частную интеграцию для своего
   аккаунта, а не публичное приложение для чужих аккаунтов.
3. Заполните карточку:

   | Поле | Что указать |
   |---|---|
   | Название | `Цветофор — подписки сайта` |
   | Описание | `Автоматически создаёт сделки из сайта подписок и отмечает первую оплату.` |
   | Сайт / адрес интеграции | `https://цветы.цветофор.рф` |
   | Права | Создание и изменение сделок, контактов и примечаний; чтение воронок, этапов и сотрудников. |

4. Сохраните интеграцию. На вкладке **Ключи и права** создайте
   **долгоживущий токен**. Скопируйте его сразу: потом AmoCRM обычно не
   показывает значение повторно.
5. Не отправляйте токен в чат, почту, задачу или репозиторий.

## Передать доступ безопасно

После согласования технической настройки токен добавляется в GitHub как
секрет `AMOCRM_TOKEN`. Поддомен аккаунта (`xxx` из адреса
`https://xxx.amocrm.ru`) передаётся как `AMOCRM_SUBDOMAIN`.

Секрет видит только защищённый процесс настройки; он не попадает в Git, в
журналы работы и в код сайта. На сервере он хранится в закрытом файле
настроек. После настройки сайт проверяет доступ к API без создания сделок.

## Выбрать воронку и этапы на сайте

Когда доступ подключён, откройте админку сайта → **Настройки сайта** →
**AmoCRM**.

- Выберите воронку из списка по названию.
- Выберите этап для новой заявки.
- Выберите этап после первой оплаты.
- При необходимости выберите ответственного менеджера.
- Включите переключатель «Передавать заявки в AmoCRM» и сохраните страницу.

Номера воронок и этапов искать и копировать не нужно: сайт показывает их
названия и сохраняет технические номера сам. Если этап после оплаты оставить
пустым, сайт добавит примечание об оплате, но не будет менять этап.

## Проверить без риска для клиентов

1. Используйте только собственную контрольную подписку.
2. Сначала убедитесь, что в AmoCRM появилась одна новая сделка и открывается
   карточка «только просмотр».
3. Затем оплатите только собственную первую подписку и убедитесь, что сделка
   перешла на выбранный этап.
4. В журнале проекта запишите дату, номер подписки и номер сделки без ФИО,
   телефонов, адресов, токенов и платёжных данных.
